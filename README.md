# Sazzo · demos de software por rubro

👉 **Catálogo:** https://sazzo-digital.github.io/

Demos de software para negocios, en **modo prueba**: se abren desde el celular, se prueban con un toque y no piden
cuentas ni contraseñas. Los datos son inventados y quedan guardados solo en el dispositivo de quien prueba.

## Las demos

| Demo | Para | Probarla |
|---|---|---|
| Flota | Empresas con vehículos: remiserías, fleteras, distribuidoras | [abrir](https://sazzo-digital.github.io/flota/) |
| Kiosco | Kioscos, almacenes y dietéticas | [abrir](https://sazzo-digital.github.io/kiosco/) |
| Canchas | Canchas de fútbol y pádel | [abrir](https://sazzo-digital.github.io/canchas/) |
| Barbería | Barberías, peluquerías y estética | [abrir](https://sazzo-digital.github.io/barberia/) |
| Taller | Talleres mecánicos | [abrir](https://sazzo-digital.github.io/taller/) |
| Perfumería | Perfumerías y tiendas de cosmética | [abrir](https://sazzo-digital.github.io/perfumeria/) |
| Restix | Bares y restaurantes | [abrir](https://sazzo-digital.github.io/restix-web/) |

Cada demo se puede ver con los colores del negocio ("Probala con tus colores") y vuelve al catálogo con
"Ver otras demos".

## Cómo está hecho

- HTML, CSS (escrito en SCSS) y JavaScript con módulos, sin frameworks. Solo web: no hay nada que instalar.
- Un kit común a todas las demos (guardado en el dispositivo, rutas, temas claro y oscuro, colores por negocio,
  topes contra valores absurdos), con más de 300 pruebas automáticas.
- Registro de visitas anónimo: cuenta aperturas y pantallas por demo, sin nombres, teléfonos, mails ni ubicación
  (Google Apps Script).

Este repositorio es el sitio ya armado: se genera automáticamente y no se edita a mano.
