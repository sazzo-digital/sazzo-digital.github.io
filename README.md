# Sazzo · demos de software por rubro

👉 **Catálogo:** https://sazzo.com.ar/

Demos de software para negocios, en **modo prueba**: se abren desde el celular, se prueban con un toque y no piden
cuentas ni contraseñas. Los datos son inventados y quedan guardados solo en el dispositivo de quien prueba.

## Cómo está hecho

- HTML, CSS (escrito en SCSS) y JavaScript con módulos, sin frameworks. Solo web: no hay nada que instalar.
- Un kit común a todas las demos (guardado en el dispositivo, rutas, temas claro y oscuro, colores por negocio,
  topes contra valores absurdos), con cientos de pruebas automáticas.
- Registro de visitas anónimo: cuenta aperturas y pantallas por demo, sin nombres, teléfonos, mails ni ubicación
  (Google Apps Script).

Este repositorio es el sitio ya armado: se genera automáticamente y no se edita a mano. Se publica en el dominio
propio sazzo.com.ar (la dirección sazzo-digital.github.io lleva sola a la nueva).
